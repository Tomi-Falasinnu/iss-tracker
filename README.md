First addition to the project.
What it is: I am building an ISS Tracker, a small web application that tracks the International Space Station in real time.
How it works: It fetches live coordinates from a public space API and automatically updates the station's location on a digital map every 5 seconds.
It shows a moving marker on the map, leaves a visible trail of where the space station has recently traveled, and includes simple buttons to turn the trail on or off.
How I made it: It is an AI-assisted learning project. I used AI to help generate the core code, and then I reviewed, tested, debugged, and configured everything to make it run locally on my computer
